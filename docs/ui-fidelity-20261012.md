# 8자어때 캡처 기반 보관함 UI 1차 구현 및 검증

작업 브랜치 `codex/ui-8ja-vault-fidelity`, 대상 `codex/offline-android-vault`. 원본 Android 앱은 18.2.8이며 스크린샷 19장을 사용자에게서 받았다.

## 원본 화면에 충실하게 재현한 부분

- 상단 닫기 모양 버튼 및 사용자 추가·관리 아이콘
- 밝은 회백색 세 개의 바로가기(커스텀, 궁합 모드, 설정)
- 친구/최근 입력 2개 탭, 검색창과 정렬 선택기
- `me → 즐겨찾기 → 친구`의 목록 구획, 나이 배지, 상하 일주 한자, 이름, 날짜·시간·보정 표시, 즐겨찾기 별
- 원본 캡처에서 me 1행, 즐겨찾기 7행, 친구 156행; 실제 데이터 엔트리 중 자기 항목은 목록에 중복 표시될 수 있음

원본 이미지와 개인정보를 커밋하지 않았다. 아이콘은 새 SVG로 구현하고 앱의 기존 계산 코드는 재사용한다.

## 검사

`npm test`로 전체 테스트 63개 통과, `npm run build:mobile` 성공. GitHub Actions 재실행: https://github.com/newwonwoo/saju/actions/runs/38154998740

개발 브라우저 Chromium + Playwright에서 320·360·390·412·800px의 수평 넘침 0, 163개 원본 보관 엔트리 기준 표시, 친구·최근 탭, 검색, 두 종류 정렬, 즐겨찾기 반영, 압축 보기, 궁합 2명 선택을 검증했다. 테스트 중 외부 네트워크 호출 없이 오류가 발생하지 않았다. 원본 사이트와 픽셀 크기까지 완전 동일하다고 주장하지 않는다.

## 안전

모델·SQLite·백업·복원·Android 네이티브 코드·서명키를 수정하지 않았다. 개인용 APK 및 출생 정보가 들어 있는 개인 JSON은 공개 저장소에 들어가지 않았다. 새 버전 설치 파일은 추가로 빌드/서명/실기기 확인하기 전까지 배포하지 않는다.
